# Monthly organic-media observation log

Status: Empty baseline — no publication or channel observation recorded

This log records observable facts and editorial corrections. It must not be
used to claim causality, guaranteed search impact, growth, authority, or
reputational change.

## Field definitions

| Field | Definition |
|---|---|
| Observation ID | Stable ID such as `OBS-2026-08-001` |
| Month | `YYYY-MM` reporting month |
| Channel | Website, Medium, Substack, GitHub, Notion, or approved community |
| Item ID | `ART-##` or `THR-##A/B` |
| URL | Observed URL; leave blank when not available |
| Publication date | Date shown by the channel, if any |
| Status | Planned, Draft, Canonical approved, Published, Withdrawn, or Pending |
| Query / preview observation | Exact query, snippet, preview, crawl message, or reader question observed |
| Correction | Factual/editorial correction made or `None recorded` |
| Reviewer notes | Source, date checked, uncertainty, and follow-up |
