# Outreach Index

This directory contains a controlled planning track for Axodus organic media
and external-communication materials. Planning is active; publication,
submission, or contact with external parties remains separately gated.

## Current status

- paid media, advertising, and sponsored coverage are excluded
- external emails and directed outreach remain deferred
- grant materials are deferred
- institutional contact materials are deferred
- organic publication requires human review and explicit authorization for
  each external channel

## Agent use rules

- Do not publish, submit, or contact external parties by default.
- Use the organic-media program for owned-channel planning and drafts.
- Do not treat repository visibility as communication authorization.
- Use this directory only after a separate explicit authorization opens an
  outreach track.
