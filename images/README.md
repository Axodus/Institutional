# Image bank

This directory is the source hub for generated and collected editorial
visuals. It is not the publication location for an article asset.

Approved or selected images must be copied into the corresponding article
workspace and renamed using this convention:

- articles/ART-##-slug/assets/hero.jpeg
- articles/ART-##-slug/assets/social.jpeg (optional alternate/crop)

The local asset README records alt text, rights/source, and human approval.
Keep the original files here unchanged for provenance and future reuse.
